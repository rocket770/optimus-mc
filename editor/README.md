# Route editor

Open `index.html` in a current browser. Keep its companion files together; no server or install is needed.

1. **Open map** or use the bundled example.
2. Add supported areas and preview connections. Connections are directed; check each return path separately.
3. **Export hints** to save the route draft. **Download map** saves terrain separately.

Drag to orbit, Shift/right-drag to pan, scroll to zoom. The height cutaway reveals lower surfaces. Undo restores graph edits; drafts save locally by map hash.

[Map formats and commands](../docs/MAPS.md) / [Screenshot and navigation setup](../docs/NAVIGATION.md). Imported worlds use conservative walking previews; native captures retain their collision graph. The bundled pit also has advanced jump previews.
