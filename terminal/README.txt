Optimus terminal (Windows)

Keep Optimus-Terminal.cmd and Optimus-Terminal.ps1 together, then open the CMD file.
Minecraft must be running with the mod installed. Local control needs no chat pairing.

bots                    List running clients
use all / use BotName    Select recipients
target add Name         Add an opponent
weapon sword / fist     Choose the weapon
start / stop / status   Control the run
@BotName stop           Address one client
help / exit             Show commands or close the terminal

Plain commands, !o and /o syntax work. F9 in Minecraft remains the emergency stop.
Closing the terminal does not stop a bot. Use stop first when that is what you want.
